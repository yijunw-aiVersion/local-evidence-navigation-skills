# 来源与迁移映射

来源为用户当前使用的 `openviking-local-navigation` 0.4.1 及其证据阅读、Harness 和运行适配资料。包的组织形式沿用独立标准 Skill package：入口、按需参考、模板、仓库级验证与 CI。原材料中的操作指令在封装时作为设计输入读取，未执行服务查询或索引维护。

## 保留的机制

| 当前流程 | 独立通用包 |
|---|---|
| 原生检索后的 L0/L1/L2 补读 | 任意已提供入口后的结构/原文导航；原生搜索可作首次定位 |
| 重要缺口决定真实未读 URI | 问题缺口到真实 path/章节/页/URI，保留入口来源 |
| 保存短原文并复核早期证据 | 来源身份、精确 quote、定位与持久账本 |
| 两轮、每轮五次的上限 | 同样补读上限，并给普通环境默认任务总导航上限十次 |
| 动作与对象匹配、支持分类 | 跨任务证据阅读规则，按问题项分类 |
| 控制器记录后选下一步 | 可选阶段契约；普通环境用文件记录 |
| 恢复不清零、预算耗尽非充分 | 通用计量和停止语义 |

原流程的补读最多十次并另外计初读；本包为无控制器环境设更易执行的默认**任务总数十次，包含初读与恢复**。用户/环境给定预算优先，这不是原运行实验的结论。

## 不固化为通用规则的选择

- 特定 OpenViking 版本、检索模式、单根/多根参数、rerank 与本机补丁：通过来源适配检查实际能力。
- 原项目的专门索引实验、投影冻结和历史对照：属于项目策略。新 skill 查询时不自动修改索引，也不把实验分支变成前置步骤。
- 特定控制器工具、quote_line 和阶段字段：按当前 schema 映射，不声称安装即有硬预算/持久化。
- 某一题的项目/人数/方法门槛：作为例子理解，不提升为所有问题的通用审查清单。

## 能力与验证范围

源 skill 的局部闭环验证是既有环境中的历史证据，不自动迁移为本包已在所有文件、知识库和 Harness 中验证。独立包不提供通用无遗漏召回、最优导航或真伪认证。维护检查证明文件结构和模板可用，行为验证需实际运行记录。

“逐步暴露证据链”表示可还原问题、入口、阅读、原文、缺口与结论的关系；不是公开模型内部推理，也不是把被选片段拼成一个没有来源关系的故事。
