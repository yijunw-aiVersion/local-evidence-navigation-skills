# 导航基线与预算

## 核心规则

| ID | 规则 | 实际含义 |
|---|---|---|
| N01 | 原问题确定证据要求 | 用户问行为、机制或完整流程，各自门槛不同；Agent 不能随意提高要求。 |
| N02 | 定位与证明分开 | 目录、摘要、排名和片段提供入口；原文及其上下文支持回答。 |
| N03 | 以来源邻域逐步展开 | 从已知章节读到定义、条件、限制或明确引用，不重复全库召回不同片段。 |
| N04 | 先保留原文再补读 | 保存定位和精确引文；后读章节未提到旧事实，不使旧事实失效。 |
| N05 | 重要缺口驱动下一步 | 只补会影响当前结论、范围或具体程度的缺口，不给每个对象套一张检查表。 |
| N06 | 原文语义决定支持强度 | 主体、动作、对象、条件和否定匹配；“主题相关”不足以证明具体判断。 |
| N07 | 每次展开有界 | 工具次数、返回窗口、累计阅读和综合空间一起约束；不强制用满预算。 |
| N08 | 负面判断限于已读范围 | 未召回、未读、失败或截断都不是“不存在”。 |
| N09 | 同来源多章不是独立核验 | 保留来源分组、版本和时间差，不能用章节数代替独立证据数。 |
| N10 | 停止理由与充分性分开 | 已足够、无入口、重复、能力不足和预算耗尽分别记录。 |

## 局部阅读优先序

已读段落有歧义时，先检查同段上下文、表头、定义与否定；缺步骤时读同文件直接相关子节；出现条件/范围说明时读对应限制；出现可核查引用时再沿引用读指定位置。选择取决于缺口，不必按固定顺序读完全部类型。

入口必须是真实存在并可定位的 path/URI 加范围，可由目录、工具回执或已读原文发现；不要捏造章节/URI。再读同位置可用于补足上下文或修复截断，但须说明新增范围，不能当作新的独立支持来源。

初读定位允许在授权根下按原问题做一次搜索或目录检视。之后优先在已选文件中按标题、术语、定义或引用定位。搜索只是定位工具，不把所有命中当全文阅读。一个文件没有相关证据且有已发现的新入口时可转换来源；未经用户要求，不扩成新一轮全库主题搜索、多个独立子查询或索引重建。确需扩大范围时，记录缺口与新的授权来源范围。

## 默认预算

profile 未指定时：任务导航调用总数最多 10 次，补读最多 2 轮，每轮最多 5 次。总预算包括初始定位、目录/层级遍历、正文读取、同址恢复与补读；补读上限与任务总上限同时满足，不能把初读当免费。

一次实际工具请求计一次；一个请求返回多个章节仍记录全部读取范围与输入大小。调用次数不是阅读长度。本地命令同时列目录和读正文也算导航调用；不能合并大量读取来绕过预算。

为每次读取记调用 ID、阶段/轮次、目标、请求范围、实际返回范围、状态、大小及计量单位。记录账本和提交答案不计导航次数，但仍消耗模型输入/输出和批次。实际 controller 的计量与硬上限优先，模板不能制造硬门禁。

第一轮指首次“依据初读后的缺口”展开；同一轮可选多个相关小读。第二轮开始前，重新判断第一轮后仍重要的缺口。没有收益时跳过第二轮。轮内哪次读取发现问题已经充分，就停止，不为凑齐轮次继续读取。

## 窗口与恢复

初读前检查单次结果容量、模型剩余窗口、累计阅读额度、记录与综合所需批次，并预留最终回答空间。字节、字符、工具返回 token 与供应商计费 token 分别记单位，不互相等同。

工具可以按行/页/章节分段时，缩小窗口，并保留语义上下文。工具不能分段时，检查单份结果是否安全；不安全则换合法接口、请求用户提供可用入口或交付限制，不偷偷通读全文件。保存 evidence 不意味着它永远完整留在模型窗口；综合前加载相关原文记录。

恢复沿用原 task_id、账本、轮次与已用额度。已确认的格式错误按反馈修复；未知调用结果先检查已有回执/记录，避免重复。检查点分支保留历史计量，不能重开任务清零预算。源版本改变时保留历史证据，新增来源版本并重新判断，不能让旧定位指向新文本。

## 停止原因

- `sufficient`：已有证据足以回答实际问题，剩余未知不影响当前判断。
- `no_relevant_entry`：没有真实、相关且可读的新入口。
- `no_expected_gain`：重复或背景内容预计不会改善当前答案。
- `budget_exhausted`：调用/阅读/模型预算不足；保留缺口。
- `source_unavailable`：访问、解析或安全分段能力不足。
- `scope_limit` / `user_stopped`：来源范围或用户终止限制。

停止导航后仍应使用已保存证据完成可行的限定综合；必须遵守控制器的 stopped 状态或无法安全综合时，交付已有证据与缺口，不能冒充正常完成。
